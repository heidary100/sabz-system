# Sabz System Platform
# Use Case Diagram

Version: 1.0

---

# Actors

- **Customer**: B2C end-user
- **Partner**: Verified B2B business account
- **Operator**: Internal operations staff
- **Admin**: System administrator
- **System**: Automated processes (payments, notifications)

---

# Customer Use Cases

| Use Case | Description |
|----------|-------------|
| UC-001: Register Account | Create a new customer account with phone verification |
| UC-002: Browse Products | Search, filter, and view product listings |
| UC-003: View Product Details | View product info, images, specs, and stock |
| UC-004: Manage Cart | Add, remove, and update cart items |
| UC-005: Checkout | Place an order with selected items and address |
| UC-006: Make Payment | Pay for order via online payment gateway |
| UC-007: Track Order | View order status and delivery progress |
| UC-008: View Order History | List past orders with details |
| UC-009: Manage Profile | Update personal info, addresses, and preferences |
| UC-010: Manage Wishlist | Add and remove products from wishlist |
