# Sabz System Platform
# User Stories

Version: 1.0

---

# Overview

This document contains the user stories that drive feature development for the Sabz System Platform. Each user story follows the format:

> As a **[role]**, I want to **[action]**, so that **[benefit]**.

User stories are organized by module and mapped to the product backlog. For the full prioritized backlog, see [Product Backlog](../01-planning/product-backlog.md).

---

# Authentication & Identity

- As a customer, I want to register with my phone number so that I can create an account.
- As a customer, I want to verify my phone via OTP so that my account is secure.
- As a customer, I want to log in with my phone and password so that I can access my account.
- As a partner, I want to register my business so that I can access wholesale pricing.
- As an admin, I want to manage user roles so that I can control platform access.

---

# Partner Management

- As a business owner, I want to apply as a partner so that I can get wholesale prices.
- As a partner, I want to upload my business documents so that my account can be verified.
- As an admin, I want to review and approve partner applications so that only verified businesses get tier pricing.
- As a partner, I want to see my assigned tier so that I know my pricing level.

---

# Product Catalog

- As an admin, I want to create and manage products so that customers can browse them.
- As an admin, I want to organize products into categories and brands so that customers can navigate easily.
- As a customer, I want to search and filter products so that I can find what I need.
- As a customer, I want to view product details, images, and specifications so that I can make informed purchases.

---

# Pricing Engine

- As a partner, I want to see tier-based pricing automatically so that I get the correct wholesale price.
- As an admin, I want to configure pricing rules so that different tiers get appropriate discounts.
- As a partner, I want to request a quote for bulk orders so that I can negotiate pricing.

---

# Inventory Management

- As an admin, I want to manage stock levels so that product availability is accurate.
- As a customer, I want to see stock availability so that I know if a product is in stock.
- As an admin, I want to receive low-stock alerts so that I can reorder products.

---

# Shopping Cart & Checkout

- As a customer, I want to add products to my cart so that I can purchase them later.
- As a customer, I want to proceed to checkout so that I can complete my purchase.
- As a customer, I want to see order summary before payment so that I can verify my order.

---

# Order Management

- As a customer, I want to view my order history so that I can track past purchases.
- As a customer, I want to track my order status so that I know when to expect delivery.
- As an admin, I want to manage and update orders so that I can ensure smooth fulfillment.

---

# Payment Management

- As a customer, I want to pay online so that I can complete my purchase securely.
- As an admin, I want to view payment transactions so that I can reconcile accounts.
- As a customer, I want to receive payment confirmation so that I know my order is being processed.
